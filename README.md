# 我的生活城

会员旅程概念 Demo：滑动铺路、建筑生长、经历相连，最后拉远揭晓个人生活城。

手机和电脑均可体验。点击自动播放，或拖动时间线回看。

所有地点、评价和消费记录均为虚构；场景不代表实际地理位置或出行路线。

下载 `index.html` 后，用电脑浏览器打开即可体验。

## 时间旅程版（独立保留初版）

- 初版：`index.html`，原有地址和体验保持不变。
- 新版：`journey.html`，支持近一个月、半年、一年总览、时间回放、地点历史和权益明细。
- 新版右上角的演示设置可切换概念会员身份、主题季，并模拟新地点或老地点新增记录。
- 演示时钟固定为 2026-10-08；会员等级名称和所有记录均为虚构。切换范围、回放进度与累计历史有明确口径。
- 下载 `journey.html` 可独立离线打开，无需外部依赖。模拟记录仅在本次页面会话生效。

在线新版：https://skjv6ttj4c-commits.github.io/growing-city-demo/journey.html

## 滑动生长版

`stroll.html` 以手机原生滚动控制镜头、建筑生长、重复消费痕迹与结尾全景。反向滑动可回看，顶部可切换近一个月、半年、一年；结尾再展开地点和权益依据。采用主题叙事，不暗示连续消费时间或实际路线。支持减少动态效果偏好。

在线体验：https://skjv6ttj4c-commits.github.io/growing-city-demo/stroll.html

此前两版文件和地址均保留。

## 镜头漫游版

`lens.html` 将节点放大为近景，标题与记录跟随建筑的屏幕投影出现，次数、评价、日期与会员优惠直接展示。使用全页原生滚动惯性、轻量镜头跟随，以及阅读点附近的弱停靠；支持反向回看和减少动态效果。

更新为黑钻紫色版本：首先展示全城，点击“看看本月城事”后，用连续镜头推近进入漫游。进入前不展示时间选择器，也不启动长页滚动。

首屏视觉示例按指定文案展示：黑钻权益使用 7 次、新相遇的店铺 2、本月留下评价 2。此组为独立概念展示数字，页面已标注“首屏数据为概念示例”，不从下方时间漫游的示例账本推导；后续真实数据接入需统一统计口径。首屏采用放大衬线数字、粗体入口，以及纯 CSS 半透明弧面与细纹理；不增加图片下载或循环动画。

底部半圆相机轮盘支持圆弧拖动、点击标签和键盘方向键。松手后吸附并切换近一周／近一个月／近半年；拖动过程中只预览刻度，不重建内容。若当前地点在新区间仍有记录，则保留该地点。结尾再次拉远展示全城。

示例时钟固定为 2026-10-08，而非用户当前日期。近一周为 10.02—10.08；近一个月按最近30天统计，为 09.09—10.08；近半年为 04.09—10.08。入口“本月城事”为叙事名称。对应实际使用权益为 1 次 / ¥10、4 次 / ¥23、11 次 / ¥70，不将未使用券额计入节省。

在线体验：https://skjv6ttj4c-commits.github.io/growing-city-demo/lens.html

`node build-lens.mjs` 复用 `stroll.html` 的城市资产与数据，结合 `lens-source.html` 与 `lens-runtime.js` 生成独立可下载的 `lens.html`。不会改动既有三个版本。

本次修改前的镜头版完整保留在 `lens-classic.html`，可单独下载或访问。初版 `index.html`、`journey.html` 和 `stroll.html` 保持原样。参考图片仅用于紫色、珠光和金属质感，不引入图片中的营销布局、商品、图案或文案。

## 保留的下一阶段概念（本次不实施）

由“生活城”向“生活浮景”演化：不把所有消费强行映射成建筑，而是使用商品、体验代表物和少量有依据的情境，形成记忆小景。用连续的生活轨迹和镜头串联，而非商品货架。首次体验新增小景；重复选择在原处积累细节；UGC成为个人痕迹；等级只影响呈现待遇，不改写真实经历；权益和节省显示真实记录。保留近景阅读、随物文字和末尾全貌。需用户后续确认后才改造，当前仍是建筑版。

## 验证

可用 `PLAYWRIGHT_MODULE=/absolute/path/to/playwright node test-lens.cjs` 运行回归测试（需要可用的本机 Chrome；从仓库目录运行）。默认尝试正常安装的 `playwright` 包。测试临时启动仅监听本机的静态服务器，不需要部署服务。

已检查 390×844 与 320×568 手机模拟、桌面居中、原生触屏滚动、轮盘松手提交、周月半年统计、跨时间范围保留咖啡节点、减少动态效果、键盘和独立 HTML 离线打开。触屏测试为浏览器模拟，不等同于真实 iOS / Android 设备验收。
